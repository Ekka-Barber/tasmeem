京都・西陣にある小さな日本茶の店「一葉茶房」のトップページをデザインしてください。

事実（このまま使い、他の情報は加えないこと）:
- 宇治の契約農家から仕入れた煎茶・玉露・ほうじ茶を量り売り（50g から）。
- 店内で急須の淹れ方を教える「一煎体験」：30分、1,800円、要予約。
- 営業時間：10:00〜18:00、水曜定休。
- 住所：京都市上京区西陣。
- 対象：日本茶に興味のある地元の人と、落ち着いた体験を求める旅行者。

成果物：インライン CSS の `index.html` 1ページ、日本語、本番品質、スマートフォンとデスクトップ対応。画像は `assets/` に置くこと。
